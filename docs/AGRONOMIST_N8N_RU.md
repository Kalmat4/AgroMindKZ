# AgroMind KZ — нативный AI Agent n8n

Сценарий основан на примере пользователя: AI Agent, Anthropic Chat Model и инструменты OpenWeatherMap. Code и HTTP Request для модели/погоды не используются.

## Схема
Webhook → If (Valid Request) → Edit Fields (Prepare Context) → If (Has Photo) → Convert to File при наличии фото → AI Agent → Respond to Webhook.
К AI Agent подключены Anthropic Chat Model, Current Weather и Weather Forecast.

Бэкенд передаёт schema_version=2, message, context.location.point.lat/lon, context.location.scope, context.field, history, image, mediaType, user_id и sessionId. Laravel проверяет принадлежность чата и выбранного поля текущему пользователю. Первый sessionId может быть null.

## Поле с карты пожаров → ИИ
Выберите сохранённое поле в разделе карты «Мои поля». Оно сразу становится контекстом ИИ-агронома; повторно вводить координаты в чате не нужно. Кнопка «Спросить ИИ-агронома» в карточке поля открывает чат без автоматической отправки сообщения. В чате отображаются название, культура, площадь и координаты выбранного поля.

Браузер отправляет в POST /n8n/crop `fieldId`. Laravel читает это поле из базы через текущего пользователя и подставляет сохранённые координаты в `context.location.point`, а название, культуру и площадь — в `context.field`. Координаты термоточки и центр открытой области не заменяют координаты выбранного поля. Этот же point уже используют оба инструмента OpenWeatherMap в n8n.

Переключение поля на карте действует для следующего запроса, в том числе с фото. Новый или открытый старый чат сохраняет текущий выбор карты. Запрос фиксирует выбор на момент отправки. Снятие выбора или удаление поля передаёт `fieldId: null` и очищает прежний контекст чата; без поля допускается только явно обозначенный приблизительный центр региона. Недоступный или чужой ID возвращает 422 до обращения к n8n. Для старых клиентов остаётся поддержка `field` с ручной точкой; если параметры поля отсутствуют, сохранённый в чате ID повторно проверяется и координаты заново читаются из базы.

OpenWeatherMap использует выражения из текущего Webhook: locationSelection=coordinates, latitude и longitude из context.location.point. Нет фиксированного города и нет параметров координат от модели. Инструменты: currentWeather и 5DayForecast, metric, русский язык. Прогноз — до 5 дней с шагом 3 часа.

При region_center_approximation помощник предупреждает, что точка — центр региона. При unknown просит выбрать точку, не запрашивает погоду. При сбое сервиса не придумывает данные. Выбор вызова инструментов делает AI Agent; системные правила требуют прогноз для уборки, сева, полива и погодных решений. Это не отдельный безусловный вызов погоды на каждое приветствие.

## Фото и история
Laravel отправляет base64 JSON. Convert to File преобразует поле image в binary.image с корректным MIME. В Agent включён passthroughBinaryImages, выключен streaming. Convert очищает JSON, поэтому текст агент получает ссылкой на Prepare Context; фото берётся из binary текущего входа.

Системные правила включают признаки зрелости, уверенность, болезни/вредителей/сорняки и рекомендации по уборке. Помощник отделяет готовность культуры от погодного окна, спрашивает сорт/дату посева/измеренную влажность при необходимости и не обещает точную дату по одному фото.

История приходит из Laravel: последние 10 текстовых сообщений именно текущего чата. Simple Memory из примера не добавлена, чтобы не создавать общую память anonymous:main и не смешивать новые чаты. Предыдущие фото недоступны.

## Credentials и включение
JSON использует существующие credentials из примера: Anthropic account и OpenWeatherMap account. Их идентификаторы относятся к KINEU; при импорте в другую n8n-инсталляцию выберите собственные. Ключи в JSON отсутствуют. Модель — Claude Haiku 4.5 из примера.

Webhook настроен с Authentication=None по запросу владельца. Отдельный credential или секрет вебхука не требуется. Сервисные credentials Anthropic и OpenWeatherMap остаются подключёнными, как в примере.

После проверки credentials опубликуйте сценарий и настройте Laravel:

```dotenv
N8N_CROP_WEBHOOK_URL=https://n8n.kineu.kz/webhook/agromind-agronomist-v2
N8N_CROP_WEBHOOK_SECRET=
N8N_CROP_LEGACY=false
N8N_CROP_WEATHER_IN_N8N=true
```

`php scripts/configure-agronomist.php` переводит пустой адрес и известный старый `crop-chat` на опубликованный `agromind-agronomist-v2`, включает JSON v2 и погоду в нативных инструментах. Допустимые старые адреса: `http://77.243.80.191:5678/webhook/crop-chat` и `https://n8n.kineu.kz/webhook/crop-chat`. Скрипт сохраняет остальные настройки, секреты и права файла. Произвольный адрес не заменяется: в этом случае шаг завершается с ошибкой без вывода адреса или секретов. `--check` выполняет только проверку (0 — готово, 2 — требуется обновление, 1 — ошибка); `--env=...` позволяет явно указать файл. После применения пересоздайте `config:cache`.

При выкладке `main` на KINEU этот скрипт выполняется автоматически перед `config:cache`. Это устраняет рассогласование нового протокола JSON v2 со старым адресом в production `.env`.

Флаг WEATHER_IN_N8N включайте после публикации: он отключает дублирующую погоду в бэкенде только для чата. По умолчанию он false. Отсутствие секрета больше не переключает запрос в multipart: бэкенд передаёт структурированный JSON v2. Для старого workflow crop-chat можно явно поставить N8N_CROP_LEGACY=true. Другие погодные разделы не меняются. После настройки выполните php artisan config:clear или пересоздайте config:cache. Для привязки карты к чату нужна сборка фронтенда (`npm run build`); новые миграции не добавлены, существующие миграции чатов и полей должны быть применены.

Вебхук возвращает { "response": "ответ" }, при ошибке ИИ — 502, при неверном контракте — 422. Ошибка провайдера не раскрывается. Сохранение успешных, ошибочных и ручных executions отключено в JSON. Лимит workflow 80 секунд, Laravel ждёт n8n до 90 секунд; прокси должен позволять такое ожидание.

## Проверки
`node scripts/test-agronomist-workflow.mjs` проверяет выражения, координаты, фото, изоляцию контекста, ответы и связи реальных типов узлов. `php artisan test --filter=CropChatFieldContextTest` проверяет передачу сохранённых координат в webhook, принадлежность поля, переключение/сброс контекста, удалённые поля и запрос с фото. HTTP и погодные/спутниковые сервисы в этих тестах подменены; база SQLite находится в памяти. `npm run build` собирает обновлённый интерфейс.

До рабочего запуска отдельно проверьте на сайте два разных чата/участка, вопрос «Когда собирать?» с фото, запрос без координат и недоступную погоду. Локальные проверки не заменяют вызов реальных credentials, vision-модели и сквозной запрос с развёрнутого Laravel.
